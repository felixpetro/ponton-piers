# Понтон Пирс

Адаптивный демонстрационный сайт на HTML5 + CSS3 + JavaScript.

## Структура
- index.html
- css/style.css
- js/main.js
- images/logo.svg

## Запуск
Откройте index.html в браузере или включите GitHub Pages.

Контактная форма в демо-версии не отправляет данные на сервер: для продакшена требуется подключить backend, почту или CRM.
