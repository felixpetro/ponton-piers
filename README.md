# Демонстрационный сайт понтонных конструкций

Статический адаптивный макет на HTML5, CSS3 и JavaScript.

## Структура
- `index.html` — главная страница и секции сайта.
- `css/style.css` — оформление и адаптивные правила.
- `js/main.js` — мобильная навигация, год в подвале и демонстрационное поведение формы.
- `images/pontoon-background.png` — сгенерированное фоновое изображение для hero-блока.

## Запуск
Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки.

Перед публикацией замените демонстрационные контакты и текст, добавьте реальные фотографии/ассортимент, а также подключите форму к серверу или CRM. Категории каталога в макете не являются подтверждённым перечнем товаров компании.
